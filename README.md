# MK Training Center - Frontend

Frontend web application for MK Training Center, featuring course catalogs, student registration, skill assessment, and an admin dashboard.

## Pages
- `index.html` - Home page showcasing courses, benefits, and tools
- `courses.html` - Course catalog and curriculum details
- `about.html` - About the training center
- `contact.html` - Contact information and location map
- `register.html` - Student registration form connected to the backend API
- `assessment.html` - Interactive skill assessment quiz
- `admin.html` - Admin login portal
- `admin_dashboard.html` - Registered student data dashboard connected to the backend API

## Tech Stack
- HTML5, CSS3, JavaScript (Vanilla ES6+)
- Responsive design with CSS Grid & Flexbox
- REST API integration via `fetch`
